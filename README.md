# Agon-Fletchers_Castle
Agon port of BBC Micro Basic game, Fletcher's Castle.  

You have 10 days to build a Motte and Bailey castle by assigning tasks to your soldiers and workers.  

Original version by R.K Larder and M.C Harrison of Fernleaf Educational Software. 


## Basic Instructions  
Decide whether to look for more workers, or start working on your tasks immediately.
### Choose a location
- Different locations require different amounts of work for each task.

### Allocate Workers
- Workers need soldiers with them on each task to make sure they do their job
- If you don't set enough guards you may waste a day fending off intruders
- Only soldiers can look for food.  If you don't find enough some of your soldiers and workers will die of starvation
- Some tasks require trees to be felled in order to work on them.
